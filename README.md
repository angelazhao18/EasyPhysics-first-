# EasyPhysics

EasyPhysics helps students connect introductory physics equations to physical situations. The core curriculum follows Chapters 1–4 of OpenStax University Physics Volume 1.

Home links to every study mode and chapter.
Concepts covers 22 numbered sections with worked examples and definitions.
Practice Problems includes a question for every section, instant explanations, retries, Back and Next navigation, and chapter answer keys.
Quiz offers chapter quizzes and a 22-question cumulative quiz, with all questions shown together, one submission, and a final answer key that links to the exact lessons.
Flashcards groups terms by chapter. The terms come from the lessons.
Extra review includes the original motion, forces, energy, and momentum material, including the interactive force lab.
Progress is stored in the current browser when available.
OpenStax University Physics Volume 1 provides the chapter sequence. EasyPhysics’s lesson explanations, examples, and questions were written for this project.
